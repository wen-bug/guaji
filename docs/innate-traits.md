# 先天命格设计

## 定位

先天词条正式命名为“命格”。命格属于玩家和队友的先天特质，用来决定角色长期差异和队伍定位，不与装备随机词条混用。

装备词条负责短期替换、强化和洗练追求；命格负责角色身份、成长倾向、家园效率和自动战斗风格。第一版命格不允许普通洗练或频繁替换，只能在角色生成、玩家开局选择或后续突破觉醒时确定。

## 角色结构

每个角色最多拥有：

- 1 个主命格：决定主要定位和长期成长方向。
- 1 个副命格：提供轻量特色或家园效率。
- 0 到 1 个缺陷命格：用负面效果换取更强的方向性，主要出现在高稀有队友或特殊玩家选择中。

玩家开局可从 3 个主命格中选择 1 个。队友在招募候选人刷新时随机生成命格。稀有候选人有更高概率获得副命格、觉醒潜力或缺陷命格。

## 生成规则

队友候选人的命格品质分三档：

| 品质 | 概率 | 命格结构 |
| --- | ---: | --- |
| 普通 | 70% | 1 个主命格 |
| 优秀 | 25% | 1 个主命格 + 1 个副命格 |
| 异禀 | 5% | 1 个主命格 + 1 个副命格 + 觉醒潜力；可带缺陷命格 |

招募熟练度、福缘类命格、特殊材料或后续建筑可以提高优秀和异禀候选人的出现概率，但不应让高品质命格变成常态。

## 第一版效果范围

第一版命格优先实现低耦合效果：

- 升级成长权重：提高某些属性或五行被分配成长点的概率。
- 属性读取加成：在 `total_stat()` 或 `total_element()` 中提供小额加法或百分比修正。
- 家园效率：影响炼器 `craft_bonus`、炼丹额外出丹概率、种田收益或招募候选品质。
- 历练收益：影响战斗经验、熟练度或材料掉落概率。
- 简单战斗修正：普通攻击伤害、技能冷却、受伤减免、弱点命中收益等。

第一版暂不实现复杂行为触发器，例如低血自动护盾、治疗目标偏好、连击链、召唤物或跨成员光环。这类效果需要修改 `CombatAI` 或 `CombatController`，应在基础命格系统稳定后再扩展。

## 缺陷命格

缺陷命格用于塑造角色感，不应只是纯惩罚。每个缺陷都应该带来明确的补偿方向。

| id | 名称 | 负面 | 补偿 |
| --- | --- | --- | --- |
| `frail_body` | 体弱 | 最大生命降低 | 技能冷却降低 |
| `reckless` | 鲁莽 | 防御降低 | 攻击提高 |
| `slow_burn` | 慢热 | 战斗开始短时间行动变慢 | 战斗越久伤害越高 |
| `specialist` | 偏科 | 非主属性成长降低 | 主属性成长明显提高 |
| `solitary` | 孤僻 | 队伍辅助收益降低 | 自身输出提高 |

## 数据结构

角色成员数据新增 `innate_traits` 字段：

```gdscript
"innate_traits": [
	{
		"id": "sword_bone",
		"name": "剑骨",
		"slot": "main",
		"rarity": "rare",
		"level": 1,
		"awakened": false
	}
]
```

`DataTables` 新增 `INNATE_TRAIT_DEFS`：

```gdscript
const INNATE_TRAIT_DEFS = {
	"sword_bone": {
		"name": "剑骨",
		"description": "天生剑骨，攻伐凌厉。",
		"slot": "main",
		"rarity": "rare",
		"effects": [
			{"kind": "growth_weight", "stat": "attack", "amount": 2},
			{"kind": "normal_attack_percent", "value": 0.08}
		]
	}
}
```

效果字段建议保持数据驱动：

| kind | 用途 |
| --- | --- |
| `growth_weight` | 提高升级时某项属性或五行的抽取权重 |
| `stat_flat` | 提供人物属性加法值 |
| `stat_percent` | 提供人物属性百分比修正 |
| `element_flat` | 提供五行属性加法值 |
| `element_percent` | 提供五行属性百分比修正 |
| `normal_attack_percent` | 修正普通攻击伤害 |
| `skill_cooldown_percent` | 修正技能冷却 |
| `physical_damage_taken_percent` | 修正受到的物理伤害 |
| `element_damage_taken_percent` | 修正受到的元素伤害 |
| `alchemy_extra_chance` | 修正炼丹额外出丹概率 |
| `alchemy_output_bonus_flat` | 炼丹每份基础制作额外增加固定产物 |
| `craft_bonus_flat` | 修正炼器属性入口 |
| `craft_bonus_percent` | 百分比修正炼器属性入口 |
| `material_cost_flat` | 按任务减少材料总消耗，最低仍消耗 1 个 |
| `material_cost_percent` | 按任务百分比减少材料总消耗，最低仍消耗 1 个 |
| `farm_harvest_bonus_flat` | 种田固定提高收成 |
| `farm_extra_yield_chance` | 种田时概率额外增加 1 份收成 |
| `forge_rarity_bonus` | 炼器结果向上提升指定品阶步数 |
| `forge_rarity_upgrade_chance` | 炼器结果概率向上提升 1 个品阶 |
| `forge_rarity_min` | 炼器结果最低品阶 |
| `drop_chance_percent` | 修正材料掉落概率 |
| `task_exp_percent` | 修正熟练度获得 |
| `recruit_quality_weight` | 修正招募候选品质权重 |

生产类命格通过 `task` 限定作用范围，例如 `forge`、`alchemy`、`farm`。不写 `task` 时视为通用效果。材料减免先按百分比计算，再扣固定减免，最终最低消耗 1 个材料，避免完全免费生产破坏挂机节奏。

## 觉醒规则

命格觉醒与突破绑定，避免频繁重洗。角色达到阶段上限并完成突破时，可让主命格觉醒一次。

觉醒优先强化原方向，例如：

- 剑骨：普通攻击伤害提高，并额外提高攻击成长权重。
- 丹心：额外出丹概率提高，并小幅降低炼丹材料消耗的后续扩展成本。
- 福缘：材料掉落概率提高，并小概率提高装备掉落品质权重。

第一版可只保存 `awakened` 字段，不急于开放觉醒 UI；实现时先保证存档兼容。

## UI 展示

成员信息面板在属性和技能之间增加“命格”区域：

- 显示命格名称、品质和简短描述。
- 主命格优先显示，副命格次之，缺陷命格用单独样式显示。
- 招募候选人列表显示命格摘要，让玩家有筛选队友的理由。

命格描述应说明实际效果，不写隐藏公式。例如“攻击成长倾向提高，普通攻击伤害提高 8%”。

## 扩展边界

命格系统不替代装备、丹药和技能：

- 装备仍然是主要可替换属性来源。
- 丹药仍然负责临时 Buff 和突破材料。
- 技能仍然负责主动战斗能力。
- 命格只提供长期倾向和少量规则修正。

新增命格时优先补充 `DataTables.INNATE_TRAIT_DEFS`、本文件命格池和对应测试。若命格影响战斗 AI 行为，需要同步更新 `docs/battle-expedition.md` 的自动战斗规则。
