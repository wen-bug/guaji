# 先天命格设计

## 定位

先天词条正式命名为“命格”。命格属于玩家和队友的先天特质，用来决定角色长期差异和队伍定位，不与装备随机词条混用。

装备词条负责短期替换、强化和洗练追求；命格负责角色身份、成长倾向和自动战斗风格。第一版命格不允许普通洗练或频繁替换，只能在角色生成、玩家开局选择或后续突破觉醒时确定。

## 已实现：角色结构

角色成员数据使用 `innate_traits` 字段保存命格数组。当前实现支持在成员属性读取和招募候选生成中读取命格效果；家园生产不读取人物命格。

目标结构：

- 1 个主命格：决定主要定位和长期成长方向。
- 1 个副命格：提供轻量特色。
- 0 到 1 个缺陷命格：用负面效果换取更强方向性。

当前基础招募命格池偏向轻量加成。新候选人至少生成一个主命格，较高品质在建筑等级允许时生成副命格；数据和 UI 支持缺陷槽位，但当前不会主动随机生成缺陷命格。旧字符串命格保持兼容。

## 已实现：效果字段

命格效果保持数据驱动。当前已使用或预留的字段：

| kind | 用途 |
| --- | --- |
| `stat_flat` | 提供人物属性加法值 |
| `element_flat` | 提供五行属性加法值 |

## 已实现：生成规则

队友在招募候选人刷新时随机生成命格。候选品质按普通 70%、优秀 25%、异禀 5% 生成；优秀和异禀候选人在建筑等级允许时获得副命格。玩家开局选择、觉醒潜力和缺陷命格生成仍属后续规划。

规划品质（觉醒潜力与缺陷命格尚未实现）：

| 品质 | 概率 | 命格结构 |
| --- | ---: | --- |
| 普通 | 70% | 1 个主命格 |
| 优秀 | 25% | 1 个主命格 + 1 个副命格 |
| 异禀 | 5% | 1 个主命格 + 1 个副命格 + 觉醒潜力；招募建筑 7 级后有 35% 概率追加 1 个缺陷命格 |

缺陷命格不占主命格或副命格槽位。只有异禀角色的主命格保留觉醒潜力；普通和优秀角色不会通过常规突破获得觉醒资格。

优秀和异禀候选人的副命格仍受招募建筑容量限制：招募建筑 1-3 级时只生成主命格，4 级起才生成副命格。

招募建筑等级可影响候选人命格数量上限：

- 1-3 级：最多 1 个基础命格。
- 4-6 级：最多 2 个基础命格。
- 7-10 级：最多 3 个基础命格。

招募熟练度、福缘类命格、特殊材料或后续建筑可以提高优秀和异禀候选人的出现概率，但不应让高品质命格变成常态。

## 规划：效果范围

第一版优先实现低耦合效果：

- 升级成长权重：提高某些属性或五行被分配成长点的概率。
- 属性读取加成：在 `total_stat()` 或 `total_element()` 中提供小额加法或百分比修正。
- 历练收益：影响战斗经验、熟练度或材料掉落概率。
- 简单战斗修正：普通攻击伤害、技能冷却、受伤减免、弱点命中收益等。

暂不优先实现复杂行为触发器，例如低血自动护盾、治疗目标偏好、连击链、召唤物或跨成员光环。这类效果需要修改 `CombatAI` 或 `CombatController`，应在基础命格系统稳定后再扩展。

副命格只提供轻量功能特长，不承担角色的主要战斗定位。

## 规划：五行缺陷命格

缺陷命格用于塑造角色感，不应只是纯惩罚。每个缺陷都应该带来明确补偿方向。

| 五行 | id | 名称 | 代价 | 补偿 |
| --- | --- | --- | --- | --- |
| 木 | `withered_meridian` | 枯荣逆脉 | 最大生命 -8% | 造成有效伤害时吸血 10% |
| 火 | `burning_heart` | 烈性攻心 | 防御 -8% | 造成伤害 +10% |
| 土 | `heavy_body` | 重浊之身 | 技能冷却 +10% | 受到物理伤害和元素伤害各 -6% |
| 金 | `lone_edge` | 孤锋煞命 | 受到元素伤害 +8% | 攻击忽略 3 点防御 |
| 水 | `cold_obsession` | 寒魄偏执 | 普通攻击伤害 -10% | 技能冷却 -10% |

负面幅度建议控制在 `-5% ~ -10%`，补偿幅度可略高于同类普通命格，但需要绑定明确条件或定位。

## 规划：数值基准

| 效果类型 | 建议范围 |
| --- | --- |
| 单项成长权重 | `+1 ~ +3` 权重 |
| 普通攻击伤害 | `+5% ~ +10%` |
| 技能冷却 | `-5% ~ -8%` |
| 受到伤害 | `-3% ~ -6%` |
| 材料掉落概率 | `+3% ~ +5%` |
| 熟练度获得 | `+5% ~ +8%` |
| 经验获得 | `+3% ~ +6%` |

## 数据结构

以下示例包含规划字段（如 `growth_weight`、`normal_attack_percent` 与示例命格 `sword_bone`），仅说明目标结构；已实现命格与效果字段以上方 `INNATE_TRAIT_DEFS` 命格池和效果字段表为准。

成员数据示例：

```gdscript
"innate_traits": [
    {
        "id": "sword_bone",
        "name": "剑骨",
        "slot": "main",
        "rarity": "rare",
        "level": 1,
        "awakened": false
    }
]
```

命格定义示例：

```gdscript
const INNATE_TRAIT_DEFS = {
    "sword_bone": {
        "name": "剑骨",
        "description": "天生剑骨，攻伐凌厉。",
        "slot": "main",
        "rarity": "rare",
        "effects": [
            {"kind": "growth_weight", "stat": "attack", "amount": 2},
            {"kind": "normal_attack_percent", "value": 0.08}
        ]
    }
}
```

规划可扩展效果：

| kind | 用途 |
| --- | --- |
| `growth_weight` | 提高升级时某项属性或五行的抽取权重 |
| `stat_percent` | 提供人物属性百分比修正 |
| `element_percent` | 提供五行属性百分比修正 |
| `normal_attack_percent` | 修正普通攻击伤害 |
| `skill_cooldown_percent` | 修正技能冷却 |
| `weakness_damage_percent` | 修正命中目标五行弱点时的伤害；这是五行命格新增的唯一规划效果字段 |
| `physical_damage_taken_percent` | 修正受到的物理伤害 |
| `element_damage_taken_percent` | 修正受到的元素伤害 |
| `drop_chance_percent` | 修正材料掉落概率 |
| `task_exp_percent` | 修正熟练度获得 |
| `recruit_quality_weight` | 修正招募候选品质权重 |

## 觉醒规则

规划：命格觉醒与突破绑定，避免频繁重洗。角色达到阶段上限并完成突破时，可让主命格觉醒一次。

觉醒只强化主命格原方向，不增加新的触发行为。五行主命格的觉醒后数值以“规划：五行主命格”表为准，避免觉醒同时改变角色定位或引入额外 AI 条件。

第一版可只保存 `awakened` 字段，不急于开放觉醒 UI；实现时先保证存档兼容。

## UI 展示

成员信息面板在属性和技能之间显示“命格”区域：

- 显示命格名称、品质和简短描述。
- 主命格优先显示，副命格次之，缺陷命格用单独样式显示。
- 招募候选人列表显示命格摘要，让玩家有筛选队友的理由。

命格描述应说明实际效果，不写隐藏公式。例如“攻击成长倾向提高，普通攻击伤害提高 8%”。

## 扩展边界

命格系统不替代装备、丹药和技能：

- 装备仍然是主要可替换属性来源。
- 丹药仍然负责临时 Buff 和突破材料。
- 技能仍然负责主动战斗能力。
- 命格只提供长期倾向和少量规则修正。

新增命格时优先补充 `DataTables.INNATE_TRAIT_DEFS`、本文件命格池和对应测试。若命格影响战斗 AI 行为，需要同步更新[历练与战斗](battle-expedition.md)的自动战斗规则。
