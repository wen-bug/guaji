# 历练地图、随机遇怪与自动战斗

## 玩法流程

玩家点击家园 `fight` 节点后，HUD 打开打怪面板。点击面板执行按钮后进入 `BattleMap` 历练地图，但不会立刻开战。

历练状态下：
- `Home` 隐藏，`BattleMap` 显示。
- 角色固定在战斗站位播放 `run` 动画，角色真实坐标不移动。
- 背景远景层和地面层横向循环滚动，表现为持续赶路。
- 怪物按随机间隔刷新，默认范围是 `8.0` 到 `20.0` 秒。

完整流程为：家园入口 → 历练跑图 → 随机间隔遇怪 → 自动战斗 → 继续跑图等待下次遇怪。

## 刷怪规则

`BattleMap` 负责维护刷怪计时器。进入历练或一场战斗结束时，会重新随机下一次遇怪时间。

当计时到达并且当前不在战斗中时，`BattleMap` 发出 `monster_spawn_requested` 信号。主场景收到信号后调用 `CombatController.begin_encounter(game_state)` 创建敌人。

战斗结束后，主场景调用 `BattleMap.finish_combat()` 重置刷怪计时。因此不会出现一场战斗结束后立刻无间隔进入下一场战斗。

## 自动战斗

战斗不需要玩家干预。`CombatController` 只负责当前遭遇的一场战斗，包括敌人生成、自动攻击、技能冷却、受伤、胜负、掉落和经验结算。

一场战斗结束后：
- 主场景结算打怪熟练度。
- 清空当前战斗状态。
- 历练地图保持显示。
- 角色继续播放跑步动画。
- `BattleMap` 安排下一次随机遇怪。

## 后续扩展

当前版本不提供返回家园按钮。后续如需离开历练，可在 HUD 或地图上新增返回按钮，调用 `BattleMap.exit_expedition()`，恢复 `Home.visible = true`，并让角色退出历练跑步状态。
